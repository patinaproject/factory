# Set the priority of an issue that has none

Task text version 1.0.0.

Triage `ISSUE-1`. Read it with `tracker show ISSUE-1`. Its priority is unset.
Choose a priority with the rubric in `docs/priority-rubric.md`, set it with
`tracker set-priority ISSUE-1 <value>` (1 Urgent, 2 High, 3 Medium, 4 Low), and
post the outcome with `tracker comment ISSUE-1 --body <text>`. Change no other
issue.
