# Priority rubric

Triage sets a priority only when the issue has none. When a person already
chose a priority, triage keeps it and says so.

- Urgent: users are blocked now, or data is being lost.
- High: a visible fault with no workaround, or a release waits on it.
- Medium: a visible fault with a workaround.
- Low: waiting costs users nothing visible, such as internal tooling or polish.

Triage posts one comment whose first line is `Priority: <name>, set by triage`,
or `Priority: <name>, set by a person` when it kept a person's choice.
