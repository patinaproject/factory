# Rules and what enforces them

This table pairs each rule with what enforces it. When the operator corrects
an agent, fix the mistake, add its enforcer, and add a row here. A rule that
no code enforces also gets a line in `AGENTS.md`. A rule that only docs
enforce is a candidate for a script, check, or test.
